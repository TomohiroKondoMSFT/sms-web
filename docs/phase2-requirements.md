## 1. プロジェクトスコープ（デモ最小）

### 対象範囲（IN）
- ログイン / ログアウト（3ロール切り替えを実演）
- Admin：生徒の一覧・登録・編集・削除
- Teacher：生徒一覧閲覧・出席入力
- Student：自分のプロフィール閲覧

### 対象外（OUT）— 将来拡張
| 項目 | 理由 |
|------|------|
| 成績管理（Marksheet） | デモスコープ外 |
| 試験スケジュール / お知らせ | デモスコープ外 |
| Faculty / Class マスタ管理 | デモスコープ外 |
| 教師アカウント管理 | デモスコープ外 |
| 経理・プッシュ通知 | 元ソースがスタブのみ |

## 2. ユーザーロール定義

| ロール | 説明 |
|--------|------|
| **Admin** | 生徒データの全 CRUD が可能な管理者 |
| **Teacher** | 生徒一覧の閲覧と出席入力が可能な教師 |

## 4. 非機能要件（最小）

| 要件ID | 要件 |
|--------|------|
| NFR-001 | パスワードは Identity の PBKDF2 でハッシュ化して保存する |
| NFR-002 | SQL はすべて EF Core パラメータバインドを使用する |
| NFR-003 | DB 接続文字列はコードに含めず App Service 環境変数から取得する |
| NFR-004 | HTTPS 強制・CSRF トークン付与 |

---

## 5. デモシナリオ（3分ウォークスルー）

```
① admin でログイン
  → 生徒一覧（Admin ダッシュボード）が表示される
  → 「生徒を追加」から新規生徒を登録する
  → 登録した生徒を編集・削除して確認
  → ログアウト

② teacher でログイン
  → 生徒一覧が表示される（閲覧のみ）
  → 出席入力で生徒ごとに出席 / 欠席を選択して保存
  → ログアウト

③ student でログイン
  → 自分のプロフィール（名前・クラス・学籍番号）が表示される
  → ログアウト
```
